# よみてつだい

演者のための台本アプリ

PDFの台本を読み込み、縦書きで読みながら、ラインやメモを書き込めるデスクトップアプリです。

## 主な機能

- 自分の担当役のセリフと、登場するページ・シーンの目次をハイライト
- 担当する役ごとのセリフ数を表示
- ライン・囲み・メモ・フリー記号の追加
- 見出しの設定と、シーンごとの演技の指針・フリーメモの記録
- 読み込んだ台本の役名・改行・ルビの調整
- 台本や書き込みを端末内に保存

## ダウンロード

現在は **1.2.0 検証版** を配布しています。無料でご利用いただけます。

**[ダウンロード・インストール方法はこちら](https://github.com/CocorockV/yomitetsudai/releases/tag/v1.2.0-preview.1)**

開いたページの「Assets」から、お使いの環境に合ったファイルをダウンロードしてください。

- Mac：DMGを開き、「よみてつだい」をApplicationsへドラッグしてください。
- Windows：Windows版ZIPを解凍し、中のインストーラー（exe）を実行してください。

更新する場合は、先によみてつだいを終了してください。

### 対応環境

- Mac：Apple Silicon搭載Mac（M1以降）
- Windows：Windows 11 / x64

Intel Macには対応していません。

AppleのDeveloper ID署名・公証、およびWindowsの配布用コード署名は未実施です。起動時などに警告が表示される場合があります。
