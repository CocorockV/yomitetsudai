# よみてつだい
演者のための台本アプリ

PDFの台本を読み込み、縦書きで読みながら、ラインやメモを書き込めるデスクトップアプリです。

## 主な機能

- 自分の担当役のセリフをハイライト
- ライン・囲み・メモ・フリー記号の追加
- 見出しの設定と、シーンごとの演技の指針の記録
- 読み込んだ台本の役名・改行・ルビの調整
- 台本や書き込みを端末内に保存
