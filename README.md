# yomitetsudai
よみてつだい — 演者のための台本アプリ

演者のための台本アプリ「よみてつだい」の検証版です。

対応環境：Apple Silicon搭載Mac（M1以降）
Windows・Intel Macには対応していません。

【インストール】
下のAssetsからDMGをダウンロードして開き、「よみてつだい」をApplicationsへドラッグしてください。

【確認していただきたいこと】
・初めて使用するMacでは、利用規約が表示され、台本一覧が空になっていること
・PDFを読み込み、台本が表示されること
・ラインやメモを追加し、アプリを終了・再起動しても残っていること

AppleのDeveloper ID署名・公証は未実施です。起動時に警告が出た場合は、表示された文面をお知らせください。
